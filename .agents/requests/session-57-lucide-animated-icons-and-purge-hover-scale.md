# Request: Purge Button Hover Scale & Ensure Universal Animated Lucide Icons

## Raw Request
`get rid ofd buttons hover scaling and make sure every single ui icon is using lucide-animated and actualyl animates`

## Requirements
1. **Purge Button Hover Scale**: Remove all `transform: scale(...)` from buttons and elements on hover across the entire UI.
2. **Universal Lucide Animated Icons**:
   - Ensure every single UI icon across the sidebar, header, panel docks, models, and actions uses standard Lucide SVG paths with `dsh-icon-animated` and specific animation classes.
   - Implement elegant micro-interactions (rotations, lid tilts, slider shifts, pulse, cursor movements) without scaling buttons or disturbing the layout.
