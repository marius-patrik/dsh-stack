# Request: Goal - Universal Animated Lucide Icons, Theme Customizer & Unified Plus Button

## Directives
1. **Universal Animated Lucide Icons**:
   - Ensure every single UI icon across harness, plugins, sidebars, tabs, modals, and input controls is an authentic Lucide SVG glyph.
   - Actively animate on hover (spins, tilts, shifts, pulses) and micro-interactions across all SVGs.
2. **Settings Theme Customizer**:
   - Add full color theme customizer in Settings allowing users to customize primary blurple, surfaces, borders, text, and save/create custom themes.
3. **Unified Sidebar Plus Button**:
   - All sidebar sections (Workspaces header, Pinned, Active, Host Machine, Macintosh HD, Projects, Folders, Ungrouped) MUST have the same uniform `[+]` button opening the complete New Item menu (Conversation, Terminal, Container, Workspace Directory).
   - Remove standalone terminal and three-dots buttons from section headers.
