# headless DSH profile

Native DSH profile template using the **same complete** `@dsh-stack/stack` composition as Web and TUI. Only the DSH-provided surface bundle differs (`@deepseek-ai/dsh-headless`). This profile is not an independently publishable bundle.

Install with `dsh plugin --profile headless add @dsh-stack/stack`, then run `dsh --profile headless`. DSH manages installation, overrides, and activation.
